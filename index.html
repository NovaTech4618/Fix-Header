What I Am Learning

HTML Structure

HTML provides the structure of a web page. Headings, paragraphs, links, and images help organise its content.

Page Metadata

Metadata gives browsers and other services information about a page, even when that information is not displayed as part of the main content.

Accessibility

Clear headings, meaningful links, and correct language settings can make a website easier for more people to use.
